# 과제 7 제출 조건 점검표

갱신일: 2026-09-28. 계정 삭제와 자료 처리 안내를 구현하고 별도 DB에서 검증했다. 아래 5일 기록 확인은 앞선 문서 정리 단계의 사용자 보고다. 사용자 보고에 따라 실제 5일 기록과 규칙 변경 시점 통과를 갱신했다. 9/23의 시간 겹침 때문에 비교값은 참고값이며 정확한 최종 수치나 검증된 효과가 아니다. DB·JSON 재검사, 실제 기록 수정·배포·push는 하지 않았다. 계정 삭제 관련 신규 5개와 기존 인증 9개는 이번 실행에서 통과했고, 이전 전체 68개는 반복하지 않았다.

판정 기준:

- **완료:** 해당 구현/작업과 아래 명시한 범위의 증거가 있다. 공개 운영 전체의 안전성 보증은 아니다.
- **미완료:** 필요한 기능·자료·제출물이 아직 없다. 일부 선행 작업이 되어 있어도 전체 조건을 완료로 표시하지 않는다.
- **추가 확인 필요:** 현재 점검만으로 최종 제출 상태까지 확정할 수 없다.

증거 구분:

- **이전 자동 검사:** 기존 기능 31개 + 인증 9개 + 가져오기 12개, **52개 통과·실패 0개·오류 0개**, `Ran 52 tests in 25.239s`, `OK`. 이는 이전 실행 결과다.
- **이전 구현 단계 자동 검사(이번 재실행 아님):** 기존 52개 + 신규 16개, **68개 통과·실패 0개·오류 0개**, `Ran 68 tests in 30.593s`, `OK`.
- **이전 실제 DB 확인(적용 당시):** 스키마 변경 전 SQLite 백업, 변경 후 기존 모든 테이블의 행 불변·새 이력 0행·외래키 위반 0건 확인. 기존 기록을 읽어 새 날짜별 계산 결과도 확인했다.
- **사용자 수동 확인:** 사용자가 보고한 화면 동작과 숫자만 기록했다. HTTP 상태 코드·쿠키 재사용까지 검사했다고 확장하지 않는다.

## 제출 준비 추가

공개 제출 문서와 배포 안내는 로컬에서 준비했다. 배포 계정·도메인·T07 저장소는 미정이며 공개 URL은 아직 없다. 로컬 커밋 대상 50개 파일의 금지 경로·대표 비밀 패턴 검사에서 실제 비밀값은 발견하지 못했다(테스트 표식 두 건 제외). 전체 이력 감사는 미수행이다. 로컬 커밋 SHA는 `git rev-parse HEAD`로 확인하며 원격 게시 전에는 커밋 URL 확보로 판정하지 않는다. 과거 미커밋 설명은 이전 점검 시점의 기록이다.

## 최신 확인 추가

이번에는 실제 DB를 읽기 전용으로 독립 검산하고 사용자 탈퇴 확인을 반영했다. 코드·실제 기록 변경·테스트 재실행·배포·push는 하지 않았다. 9/28 중복308초도 추가 확인하여 9/23 중복146초와 함께 해석 한계로 남긴다. 자세한 계산은 진행 문서 최신 절 참조.

## 돌아보기 구현을 코드로 확인한 결과

기존 `review.py:build_review()`의 7개 전체 집계는 보존하고, `review_experiment.py`와 `templates/review_daily.html`로 새 날짜별 분석을 추가했다. `templates/rule_change.html`에서 사용자가 규칙 변경을 입력한다. 실제 자료가 부족하면 구현된 기능도 최종 결과를 표시하지 않는다.

종료가 정확히 자정인 기록은 다음 날에 빈 0분 행을 만들지 않는다. 미기록일도 제외한다. 직접 저장된 0초 기록은 근거가 있으므로 0분 기록일로 센다. 현재까지 평균의 분모는 실제 기록일 수이고, 선택한 5일·전 2일·후 3일의 분모는 각각 5·2·3이다. 일별로 반올림한 표시값을 다시 합산하지 않는다.

기존 패널은 저장된 두 자리 분 값, 새 분석은 원래 시작·종료 시각을 사용한다. 이 차이를 화면에 명시하며 기존 원본 시간이나 예상값을 바꾸지 않았다. 3일차가 아직 없거나, 변경 시점이 잘못됐거나, 저장 뒤 근거가 바뀌면 최종 비교를 완료로 표시하지 않는다. 5일 선택에서 제외한 날짜의 이후 작업도 시점 검사에 포함한다.

최신 사용자 확인은 5일 비교 화면까지다. 9/23의 2분 26초 시간 겹침은 실제 시각을 기억하지 못해 원본을 유지하고 개선점에 한계를 기록했다고 보고했다. 이 문서에서도 임의로 빼거나 정확한 효과로 해석하지 않는다.

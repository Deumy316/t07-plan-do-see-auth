# T07 제출 안내

이 문서는 공개 저장소에 게시하면 앱 계정이나 개인 계정 로그인 없이 읽을 수 있는 제출 설명서다. 현재는 로컬 준비 상태이며 공개 앱·문서 URL은 미확정이다. T06의 기존 PythonAnywhere 주소를 T07 주소로 제출하지 않는다.

## 구현과 증거

Flask + SQLite 구조와 기존 화면을 유지했다. Werkzeug scrypt, DB의 난수 세션 해시·8시간 만료·서버 폐기, CSRF, 로그인 사용자 기준 자료 격리를 적용했다. 계정 삭제는 현재 비밀번호와 명시적 동의 후 자료와 모든 세션을 원자적으로 삭제한다. 백업과 다운로드 JSON은 자동 삭제되지 않으며 운영자가 수동 관리한다.

기존 전체 검사 68개 통과, 이후 계정 삭제 관련 신규 5개와 기존 인증 9개 통과가 각각 기록되어 있다. 이를 한 번에 73개 실행한 결과로 표현하지 않는다. 사용자는 임시 계정 브라우저 탈퇴 및 기존 자료·5일 기록 보존을 확인했다. 이번 제출 준비에서는 기존 테스트를 반복하지 않았다.

## 5일 계산과 해석 한계

원본 시작·종료 시각을 독립 계산했다. 중간값 반올림 없이 초 합계를 60으로 나누고 최종 표시만 소수 첫째 자리로 반올림했다.

9/23에는 146초(2분 26초), 9/28에는 308초(5분 8초)의 중복 합산이 있다. 실제 시각을 복원할 근거가 없어 원본을 유지했다. 이는 **저장된 기록의 참고값**이며 정확한 실제 작업 시간이나 검증된 효과가 아니다. 작업량·난이도도 같지 않아 규칙 변경의 효과를 단정하지 않는다. 규칙 변경 저장 시각 9/22 16:11:58 및 3일차 이전 검증 통과는 사용자 화면 확인 기록이다.

## 평가자 확인

공개 배포 후 앱의 첫 접근은 로그인 화면으로 이동한다. 평가자는 별도 임시 계정을 만들어 자신의 자료만 확인할 수 있다. 실제 사용자 자격 증명은 제공하지 않는다. 과거 5일 결과는 위 공개 설명과 계산 근거로 확인하며 다른 계정의 개인 자료를 열어 주지 않는다. 임시 계정으로 저장·내보내기·탈퇴를 확인할 수 있다.

앱 URL: 미확보. 공개 문서 URL: 미확보(게시 대상은 이 파일). 고정 커밋 URL: 원격 게시 전 미확보. 로컬 커밋 해시는 작업 완료 응답에서 제공한다. 실제 DB·백업·개인 JSON·비밀번호·세션·비밀키는 제출하지 않는다.
